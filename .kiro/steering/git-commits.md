# Git Commit Messages

- Use conventional commits format: `type: short description`
- Maximum 50 characters in the subject line
- No body or footer unless explicitly requested
- Types: feat, fix, refactor, docs, test, chore, style
- Write in English, lowercase, no period at the end
- Examples:
  - `feat: add admin panel with captcha login`
  - `fix: resolve tooltip overlap on mobile`
  - `test: add e2e tests for admin flow`
